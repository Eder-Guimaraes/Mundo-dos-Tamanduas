# 🌿 Mundo dos Tamanduás

Um site desenvolvido com **HTML**, **Tailwind CSS**, **Flowbite** e **JavaScript** para apresentar informações sobre os tamanduás de forma moderna, interativa e responsiva.

## 📖 Sobre o projeto

O **Mundo dos Tamanduás** é um projeto educativo que reúne informações sobre uma das espécies mais fascinantes da fauna brasileira. O objetivo é oferecer uma experiência agradável ao usuário, combinando design moderno com componentes interativos.

O projeto foi desenvolvido como atividade acadêmica utilizando conceitos de desenvolvimento web.

---

## ✨ Funcionalidades

* 🏠 Navbar responsiva
* 🌿 Hero Section
* 📝 Formulário de cadastro
* 💬 Tooltip informativo
* ✅ Modal de confirmação
* 📖 Accordion com curiosidades sobre os tamanduás
* 🖼️ Galeria de imagens em carrossel
* 📊 Tabela comparativa das espécies
* 📱 Layout responsivo para diferentes dispositivos

---

## 🛠️ Tecnologias utilizadas

* HTML5
* Tailwind CSS
* Flowbite
* JavaScript
